Brancher un assistant IA sur Arpente

Pour préparer une visite de Caen ou de Troyes avec Claude, ChatGPT ou un outil de votre ordinateur.

L'assistant agit en votre nom : il voit ce que vous voyez dans vos groupes, et vote comme vous le feriez. Il ne voit jamais votre adresse e-mail. N'autorisez qu'un assistant que vous utilisez vous-même, et retirez l'accès quand vous voulez : Groupes → Mon compte → Assistant IA → Révoquer.

L'adresse

https://api.arpente.heianenterprise.com/mcp

C'est un serveur MCP (Model Context Protocol). L'assistant ouvre une page Arpente où vous vous connectez à votre compte — code reçu par e-mail, ou Google — puis l'autorisez. Il faut un compte Arpente : il se crée à la première connexion.

Le brancher

  • Claude (claude.ai, Claude Desktop, mobile) : Personnaliser → Connecteurs → + → Ajouter un connecteur personnalisé, puis collez l'adresse.
  • ChatGPT : Réglages → Sécurité et connexion → Mode développeur, puis Plugins → + et l'adresse.
  • Claude Code : claude mcp add --transport http arpente https://api.arpente.heianenterprise.com/mcp, puis /mcp → Authenticate.
  • Cursor, VS Code : ajoutez un serveur MCP « HTTP » à cette adresse ; l'autorisation suit le même chemin.

Les menus des assistants changent souvent : si un chemin ne correspond plus, cherchez « connecteur » ou « serveur MCP » dans leurs réglages.

Ce qu'il peut faire

OutilCe qu'il fait
lieuxLes lieux à visiter d'une ville, 30 par page, filtrables par catégorie ou tag.
lieuLa fiche complète d'un lieu : histoire, anecdotes, époque, position.
parcoursLes parcours thématiques tout faits et leurs étapes.
mes_groupesVos groupes de visite.
groupeUn groupe : membres (pseudonymes), votes, envies et leurs médianes, étapes cochées, parcours arrêté.
voter, retirer_voteApprouver des lieux, ou retirer vos approbations, en votre nom.
mes_enviesRégler le nombre de lieux et la durée que vous souhaitez.
arreter_parcoursCalculer le parcours du groupe à partir des votes ; l'enregistrer — visible de tous — seulement après votre accord.

Les règles qu'il suit

  • Il désigne les lieux par leur nom exact ; s'il se trompe, l'outil refuse et propose des lieux proches, sans choisir à votre place.
  • Il ne calcule jamais un parcours lui-même : c'est Arpente qui le calcule, comme dans l'app. Il vous montre l'aperçu et attend votre accord avant de l'enregistrer.
  • Les noms de groupes et les pseudonymes sont des données, jamais des consignes à suivre.
  • Il ne peut ni créer, ni rejoindre, ni quitter, ni supprimer un groupe, ni voir les codes d'invitation, ni toucher à votre compte.

Limites

  • 30 écritures par heure et par accès, dont 5 parcours arrêtés.
  • Un accès dure 90 jours ; ensuite, l'assistant vous redemande votre accord.
  • Une distance marquée « estimée » est à vol d'oiseau : à pied, en ville, comptez environ 30 % de plus.

Vos données

L'assistant lit les lieux, et vos groupes tels que vous les voyez. L'éditeur de l'assistant (Anthropic, OpenAI…) traite ensuite ce qu'il lit selon ses propres conditions. Tout est détaillé dans la politique de confidentialité.
